# Deployment Guide

## Requirements

- Node.js 20+
- MongoDB Atlas
- Docker
- Git

## Clone Repository

git clone https://github.com/Aiden-Vihaan/second-chance-marketplace.git

## Backend Setup

cd backend

npm install

npm run dev

## Frontend Setup

cd frontend

npm install

npm run dev

## Sentiment Service Setup

cd sentiment-service

npm install

npm run dev

## Docker Deployment

docker compose up --build

## URLs

Frontend:
http://localhost:5173

Backend:
http://localhost:5000

Sentiment Service:
http://localhost:5001
