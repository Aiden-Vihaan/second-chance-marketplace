# Sentiment Service - Second Chance Marketplace

## Overview

The **Sentiment Service** is a microservice used in the Second Chance Marketplace project.  
It analyzes user reviews and comments to determine sentiment (positive, negative, neutral).

This service helps improve:
- Review quality analysis
- User trust scoring
- Product feedback insights
- Recommendation systems

---

## Features

- Text sentiment analysis using NLP
- REST API for sentiment scoring
- Clean and standardized JSON responses
- Swagger API documentation
- Input sanitization
- Unit testing with Jest
- Error handling middleware

---

## Tech Stack

- Node.js
- Express.js
- Sentiment (NPM library)
- Swagger UI
- Jest
- CORS
- dotenv
